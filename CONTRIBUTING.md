# Contributing

This repository contains practical PL/SQL work organized by semester units.

## Adding a practical

- Place the program in the appropriate unit directory.
- Keep the filename descriptive and consistent with the existing exercises.
- Include the SQL/PLSQL source needed to reproduce the practical.
- Update the README when adding a new unit or changing the repository structure.

## Verification

Run each program in Oracle SQL*Plus or a compatible Oracle environment before committing.

## Commit style

Use concise messages that describe the change, for example:

```text
feat: add cursor practical
docs: update unit index
fix: correct procedure example
```
