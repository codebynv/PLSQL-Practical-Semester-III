# PL/SQL Exam Revision Checklist

## Unit 01

- [ ] Block structure: DECLARE, BEGIN, EXCEPTION, END
- [ ] Variables and constants
- [ ] %TYPE and %ROWTYPE
- [ ] SELECT INTO
- [ ] IF and CASE
- [ ] FOR and WHILE loops
- [ ] Predefined and user-defined exceptions

## Unit 02

- [ ] Nested conditions
- [ ] Loop tracing
- [ ] Business-rule calculations
- [ ] Pattern and number problems
- [ ] Debugging control-flow mistakes

## Unit 03

- [ ] OPEN, FETCH, CLOSE
- [ ] %FOUND and %NOTFOUND
- [ ] %ROWCOUNT and %ISOPEN
- [ ] Parameterised cursors
- [ ] FOR UPDATE
- [ ] WHERE CURRENT OF
- [ ] Nested cursors

## Final practice

For each unit, trace at least one program manually before running it in SQL*Plus.
