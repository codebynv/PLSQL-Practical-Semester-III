# Procedures and Functions

## Procedure

A procedure performs an operation and may return information through OUT parameters.

## Function

A function returns a value and can be used in expressions where permitted.

## Revision checklist

- Identify parameters and their modes.
- Understand local declarations.
- Trace execution order.
- Handle expected exceptions.
- Test valid and invalid inputs.

Practice writing each routine from a short problem statement before reviewing a solution.
